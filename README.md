# Prompts abiertos de Cognenza

**IA que se entiende.** Una colección de 28 prompts en español, probados y listos para copiar, pegar y rellenar en ChatGPT, Claude, Gemini o cualquier otro asistente.

Es una selección de los prompts que ya publicamos gratis en [cognenza.com](https://cognenza.com/), la web de IA práctica en 7 idiomas. Aquí los tienes en texto plano para usarlos, adaptarlos y compartirlos.

## Cómo usar los prompts

1. Abre el prompt que necesites en la carpeta [`prompts/`](prompts/).
2. Copia el bloque de código completo y pégalo en tu asistente de IA.
3. Rellena lo que va entre `[corchetes]` con tus datos. Usa datos ficticios o anónimos: nunca pegues información personal o confidencial.
4. Revisa la respuesta. Los prompts ayudan a obtener mejores resultados, no resultados garantizados.

Todos siguen la misma estructura: **rol, contexto, objetivo, datos, pasos, formato, criterios de calidad y autorrevisión**. Si quieres crear los tuyos con esa estructura, prueba el [constructor de prompts](https://cognenza.com/utilidades/constructor-prompts/).

## Índice

### Estudio

Para preparar exámenes, trabajos y aprender idiomas.

- [Resumen de un tema para examen](prompts/estudio/resumen-de-un-tema-para-examen.md) — prompt que convierte tus apuntes en un resumen jerárquico con conceptos clave, ejemplos y preguntas de repaso.
- [Corregir una redacción con rúbrica](prompts/estudio/corregir-una-redaccion-con-rubrica.md) — prompt para recibir una corrección detallada por criterios, con nota orientativa y cómo mejorar.
- [Preparar un examen oral](prompts/estudio/preparar-un-examen-oral.md) — prompt que simula al tribunal con preguntas, repreguntas y valoración de tus respuestas para practicar.
- [Practicar un idioma con conversación guiada](prompts/estudio/practicar-un-idioma-con-conversacion-guiada.md) — prompt para conversar a tu nivel, con correcciones breves y vocabulario nuevo en cada turno.
- [Estructura de un trabajo académico](prompts/estudio/estructura-de-un-trabajo-academico.md) — prompt que organiza el índice, la pregunta de investigación y las fuentes a buscar, sin escribirlo por ti.
- [Mapa conceptual en texto](prompts/estudio/mapa-conceptual-en-texto.md) — prompt que organiza un tema en conceptos y relaciones, listo para dibujar o pegar en una herramienta de diagramas.

### Trabajo

Correos, entrevistas, CV y relaciones con el equipo.

- [Responder un correo difícil](prompts/trabajo/responder-un-correo-dificil.md) — prompt profesional para contestar con calma y firmeza, sin escalar el conflicto y con una propuesta clara al final.
- [Correo de seguimiento tras una reunión](prompts/trabajo/correo-de-seguimiento-tras-una-reunion.md) — prompt que convierte tus notas en un resumen con acuerdos, responsables y fechas para enviar el mismo día.
- [CV orientado a logros](prompts/trabajo/cv-orientado-a-logros.md) — prompt que reescribe tu experiencia con verbos de acción y resultados medibles, sin inventar datos ni exagerar.
- [Perfil de LinkedIn profesional](prompts/trabajo/perfil-de-linkedin-profesional.md) — prompt para escribir titular, extracto y experiencia que se encuentran en búsquedas y suenan a ti.
- [Respuestas STAR para una entrevista](prompts/trabajo/respuestas-star-para-una-entrevista.md) — prompt para preparar ejemplos reales con situación, tarea, acción y resultado, y practicar en voz alta.
- [Feedback constructivo a un compañero](prompts/trabajo/feedback-constructivo-a-un-companero.md) — prompt para preparar una conversación difícil con hechos, impacto y una petición clara.

### Productividad

Informes, hojas de cálculo, presentaciones y prioridades.

- [Informe mensual de resultados](prompts/productividad/informe-mensual-de-resultados.md) — prompt para pasar de datos sueltos a un informe claro con cifras clave, causas, riesgos y próximos pasos.
- [Limpiar y ordenar datos en Excel](prompts/productividad/limpiar-y-ordenar-datos-en-excel.md) — prompt con pasos para quitar duplicados, unificar formatos y dejar una tabla lista para analizar.
- [Tabla dinámica paso a paso](prompts/productividad/tabla-dinamica-paso-a-paso.md) — prompt para diseñar el resumen que necesitas, con filas, columnas, valores y filtros explicados para tu versión.
- [Presentación de 10 diapositivas con guion](prompts/productividad/presentacion-de-10-diapositivas-con-guion.md) — prompt que estructura tu mensaje, propone el contenido de cada diapositiva y qué decir en cada una.
- [Priorizar las tareas de la semana](prompts/productividad/priorizar-las-tareas-de-la-semana.md) — prompt que ordena tu lista por impacto y urgencia y la reparte en bloques de tiempo realistas.

### Programación y datos

Revisar, depurar y entender código, SQL y datos.

- [Revisar código como un sénior](prompts/programacion-y-datos/revisar-codigo-como-un-senior.md) — prompt de revisión que busca errores, problemas de seguridad y mejoras de legibilidad, ordenados por gravedad.
- [Depurar un error a partir del mensaje](prompts/programacion-y-datos/depurar-un-error-a-partir-del-mensaje.md) — prompt que analiza el error, plantea hipótesis ordenadas y propone pruebas para encontrar la causa.
- [Explicar código heredado](prompts/programacion-y-datos/explicar-codigo-heredado.md) — prompt para entender un programa antiguo, con resumen, flujo, dependencias y riesgos antes de tocarlo.
- [Consulta SQL a partir de una pregunta](prompts/programacion-y-datos/consulta-sql-a-partir-de-una-pregunta.md) — prompt que convierte tu pregunta de negocio en una consulta correcta, explicada y comprobable.
- [Expresión regular explicada](prompts/programacion-y-datos/expresion-regular-explicada.md) — prompt para crear una regex que hace lo que quieres, con explicación por partes y ejemplos de prueba.
- [Analizar un conjunto de datos CSV](prompts/programacion-y-datos/analizar-un-conjunto-de-datos-csv.md) — prompt para explorar datos, encontrar patrones y obtener conclusiones con cifras, gráficos y límites claros.

### Escritura

Relatos, corrección de estilo, traducción y respuestas a clientes.

- [Relato corto con estructura](prompts/escritura/relato-corto-con-estructura.md) — prompt para escribir una historia con personaje, conflicto y giro, respetando tu estilo y la extensión pedida.
- [Corregir estilo sin cambiar la voz](prompts/escritura/corregir-estilo-sin-cambiar-la-voz.md) — prompt para pulir un texto propio con cambios mínimos y explicados, sin que suene a inteligencia artificial.
- [Traducción profesional con glosario](prompts/escritura/traduccion-profesional-con-glosario.md) — prompt que traduce respetando terminología, tono y formato, y señala las dudas para revisarlas.
- [Adaptar un texto a otro mercado](prompts/escritura/adaptar-un-texto-a-otro-mercado.md) — prompt de localización que ajusta referencias, ejemplos, unidades y tono al país de destino.
- [Responder una reseña negativa](prompts/escritura/responder-una-resena-negativa.md) — prompt para contestar en público con empatía y profesionalidad, sin discutir y ofreciendo una solución.
